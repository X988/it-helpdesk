# Аудит APK Extractor

Статически проверены все Android-исходники, манифест, ресурсы, настройки Gradle и оба workflow.

Исправлены:
- manifest.json сохранял `${jsonEscape(it)}` буквально вместо splitName. Теперь используется общий JSON-кодировщик; 5 unit-тестов проверяют данные, escaping и безопасные имена файлов.
- Список приложений для экспорта терялся при пересоздании Activity, пока открыт системный выбор папки. Теперь он хранится в rememberSaveable.
- README предлагал отсутствующий в checkout ./gradlew. Описаны Gradle 8.13 и генерация wrapper.
- Добавлены обязательные unit-тесты и Android Lint к debug-сборке для pull request в Android-ветку.

Файлы пишутся через SAF, временно созданный документ удаляется при обычном отказе. Экспорт не отправляет данные по сети, разрешение INTERNET отсутствует. Исходный файл APK может измениться при обновлении приложения во время экспорта; при ошибке следует повторить экспорт после обновления. APKS — собственный ZIP с manifest.json, не заявляет совместимость с установщиками иных форматов.

Ограничения: нет проверки на физическом устройстве/эмуляторе, публикации release и подписи владельца. Theme/выбранная папка не сохраняются после завершения процесса. Успех debug-сборки не подтверждает правила магазина или работу всех DocumentProvider. Проверить отдельно API 26 и 36, split APK, rotation, недостаток места и отзыв SAF-разрешения. QUERY_ALL_PACKAGES заявлено только для функции списка установленных пакетов; публикация требует отдельной проверки требований магазина.

Android Lint имеет точечное исключение QueryAllPackagesPermission на самой
декларации: функция sideload-приложения — полный список установленных APK,
включая пакеты без launcher Activity. Остальные ошибки Lint блокируют CI.
Это техническое решение не означает разрешение публикации в магазине.
Основание: [Android package visibility](https://developer.android.com/training/package-visibility/declaring#all-apps).

Остаются 7 предупреждений Lint:
- OldTargetApi: target 36 оставлен до проверки поведения на следующей версии ОС.
- Обновления Activity, Lifecycle и Coroutines: три сообщения; совместное обновление
  с Compose проверяется на устройстве, без слепой замены рабочих закреплённых версий.
- DataExtractionRules: для Android 12+ стоит уточнить правила переноса данных,
  особенно на устройствах с отличающимся поведением backup. Сейчас allowBackup=false;
  экспортированные пользователем документы находятся у выбранного SAF-provider.
- Две рекомендации UseKtx (toUri/createBitmap), не меняющие наблюдаемое поведение.

Эти предупреждения доступны в полном отчёте, не скрыты глобальным baseline.
